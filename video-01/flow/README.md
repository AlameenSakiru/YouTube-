# Flow automation files for video 1

| File | Use it when your automation tool wants |
|---|---|
| `flow-prompts.txt` | One prompt per line. **Start with this one.** 73 lines, line 1 is image 001 |
| `flow-prompts.docx` | The same 73 prompts in a Word file, one per paragraph, ready to copy and paste |
| `flow-prompts-blank-lines.txt` | Prompts separated by an empty line |
| `flow-prompts.csv` | A spreadsheet. Columns: file name, optional, prompt |
| `flow-thumbnails.txt` | The 3 thumbnail prompts, one per line. Run these separately |

- Set the tool to the wide **16:9** shape and the highest image quality your plan allows.
- Every prompt is complete. Do not add anything in front of it or after it.
- Line order is image order. If the tool names files by number, they match `001.png` to `073.png`.
- If the files come out with other names, send them anyway: I can look at each image and match it to its shot.
- The same prompts, with timings and the narration each image goes with, are in [../image-prompts.docx](../image-prompts.docx).
